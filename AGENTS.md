# enscribe.dev

## Browser support

Target Baseline 2024. A feature that became Baseline in 2024 or earlier ships
without a fallback, and prefixed duplicates of it are removed.

A newer feature is progressive enhancement. It keeps a fallback only when
losing it breaks a control (the search trigger, the dialog backdrop click, the
table of contents progress ring). Decorative effects such as the scroll fades
go without one.
